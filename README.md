# 半導體晶圓良率異常預警與根因排查（POC 實作筆記）

> **專案備忘**：利用公開開源資料集（UCI SECOM）進行技術驗證與思路梳理之 Side Project，所有數據與程式碼皆為公開資訊，無涉及任何特定企業內部資料。

---

## 1. 核心痛點與解題背景

* **少數樣本極度稀缺**：瑕疵品（Fail）佔比僅約 6.6%（正負樣本比約 1:14）。若直接使用常規演算法，模型易產生全數預測為良品的盲區，造成嚴重漏報。
* **高維雜訊與空值干擾**：資料涵蓋 590 個感測器訊號，多數欄位缺失率極高或屬於無數值變化的常數特徵，雜訊干擾嚴重。
* **排查拒絕黑盒子**：僅輸出異常機率無法支援第一線工程處置，必須具備具體的感測器偏差定位（Root Cause），排查才有實際著力點。

---

## 2. 實作架構流程

```text
[590 個感測器原始特徵]
          │
          ▼
[資料前處理] 剔除高缺失與零變異欄位 ➔ 訓練集統計量中位數填補
          │
          ▼
[不平衡處理] 放棄合成生成 (SMOTE) ➔ 採用代價敏感加權 (scale_pos_weight)
          │
          ▼
[模型訓練] 淺層樹防禦設計 (LightGBM) ➔ Early Stopping 驗證
          │
          ▼
[根因歸因] 輸出高風險警報 ➔ TreeSHAP 萃取關鍵偏差感測器



實驗紀錄與避坑梳理
合成樣本（SMOTE）評估：

在高維空間（500+ 維度）合成樣本易模糊決策邊界，實測導致假警報（False Alarm）激增近 30%。後續改採直接調整損失函數加權（scale_pos_weight），模型收斂與少數類識別表現顯著回穩。

特徵預篩與降維效益：

清查發現逾 110 個感測器為常數或缺失率超過 45%。先行剔除無效維度後，訓練推論時間縮短近半，且無損整體分類精度，同時減輕後續決策樹分裂負擔。

評估指標切換：

在極度不平衡情境下，ROC-AUC 易呈現過度樂觀之假象。離線驗證全面改採 PR-AUC 作為基準，並以「排查量能限制下的 Top-K 異常命中率」評估實務可用性。
